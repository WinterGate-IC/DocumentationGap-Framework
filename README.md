# DocumentationGap-Framework

**The space between what platforms claim and what they demonstrably do.**

---

## What This Repository Is

This is a framework repository. It contains analytical documents about the documentation gap — the measurable distance between committed action and recorded action, and the place where harm survives.

It is not a list of bad platforms.
It is not a call to action against any party.
It is not a substitute for law enforcement or platform moderation.

It is a set of working documents about **evidentiary infrastructure** — what it takes to make harm provable to a decision-maker who was not there, and what it takes to make non-action visible when it happens.

---

## Why It Exists

Platforms write policies they enforce selectively, document enforcement minimally, and cite scale as though it were a law of nature rather than a design decision. The result is a gap between what is promised and what is recorded.

The gap is not an accident. It is an allocation decision, made quarterly, measured against metrics that do not include the harm it fails to prevent.

This repository documents the gap, names its layers, catalogues the language used to describe it as a condition rather than a choice, and specifies a closure protocol that can be applied from outside the platform.

## The Standards This Repository Holds Itself To

Every document added to this repository is expected to meet the same six requirements the framework itself specifies for evidence:

1. **Verifiability** — every claim linked to a publicly accessible source
2. **Timestamping** — every event anchored to date and time
3. **Separation** — verified facts explicitly separated from allegations
4. **Non-expansion** — public handles and public content only, never private identifiers
5. **Chain of custody** — documentation of how evidence was obtained and preserved
6. **Retrievability** — published in a medium a third party can access and cite

A document that does not meet these standards does not belong in this repository.

## What This Repository Is Not

- **Not a target list.** Nothing here instructs anyone to act against any person or organization.

## How to Read the Framework

The core document is structured so that it can be read in layers:

- **If you have five minutes:** read the Abstract and the Conclusion.
- **If you want the definition:** read Part I.
- **If you want to know why the gap persists:** read Part IV.
- **If you have ever submitted a report and received a reply that felt like a refusal:** read Part V.
- **If you want to close a gap in your own perimeter:** read Part IX.
- **If you want to measure whether a gap has closed:** read Part X.

Part V is the center of gravity. It catalogues the twenty-one phrases platforms use to describe non-enforcement as though it were a natural condition. The scale defense — *"it is too big"* — is examined in detail, because it is the most common refusal and the least examined.
